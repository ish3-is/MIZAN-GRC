# Security policy

Do not report real credentials or personal data in a public issue. This repository contains only fictional demonstration data and locally generated secrets.

For a vulnerability in the code, privately contact the repository owner through GitHub security advisories if enabled. Include the affected version, reproducible steps, impact and a minimal proof of concept without real data.

Supported portfolio version: 0.2.x. This project is not represented as production-ready. Known limits include single-organization deployment, no enterprise SSO/MFA, no malware scanner, local evidence-key management, no external audit-log anchoring and no independent penetration test. See [the full threat model](docs/SECURITY.md).
