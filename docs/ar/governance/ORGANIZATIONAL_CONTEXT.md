# نماء للحلول الرقمية — السياق التنظيمي

> محاكاة افتراضية لأغراض العرض المهني. لا تمثل منشأة أو عميلاً أو موظفاً أو تدقيقاً حقيقياً.

نماء للحلول الرقمية شركة سعودية متوسطة الحجم تعمل في تقنية المعلومات والخدمات الرقمية ضمن سيناريو يضم 150 موظفاً. تقدم خدمات افتراضية للأفراد والشركات عبر بوابة العملاء ونظام إدارة العلاقات وتخطيط الموارد والموارد البشرية والبريد وإدارة الهوية ومنصة النسخ الاحتياطي. تعمل البنية بصورة هجينة بين السحابة ومقر المنشأة. يضم سيناريو فريق الأمن السيبراني أربعة أدوار وتقنية المعلومات اثني عشر دوراً؛ ويستخدم البذر عينة ممثلة بدلاً من إنشاء ملفات شخصية وهمية واسعة.

## الأطراف المعنية وتوقعاتها

| الطرف | التوقع في بيئة العرض |
|---|---|
| مجلس الإدارة والراعي التنفيذي | قرارات مبنية على المخاطر وملكية مسؤولة واعتماد للمخاطر المتبقية |
| العملاء | خدمات موثوقة وحماية مناسبة لبيانات العملاء الافتراضية |
| الموظفون | سياسات واضحة ووصول مناسب للمهام وقنوات إبلاغ قابلة للاستخدام |
| الجهات التنظيمية | انطباق موثق وسجلات دقيقة وغير مضللة |
| الموردون | متطلبات أمن وخصوصية وأدلة وإنهاء علاقة محددة |
| التدقيق الداخلي | وصول مستقل إلى المصادر والأدلة والقرارات القابلة لكشف العبث |

## الخدمات الحرجة والاعتماديات

تُعامل بوابة العملاء (RTO أربع ساعات وRPO ساعة)، وإدارة الهوية (RTO ساعتان وRPO خمس عشرة دقيقة)، وتخطيط الموارد والرواتب (RTO ثماني ساعات وRPO أربع ساعات) كأهداف تنظيمية للمحاكاة وليست متطلبات نظامية. وتعتمد على الهوية والشبكة والاستضافة والنسخ الاحتياطي وملاك الأنظمة والموردين الرئيسيين.

## النطاق والافتراضات

يشمل النطاق الإدارات الافتراضية الثماني والأصول المعلوماتية الخمسة والعشرين والموردين الخمسة. تُستخدم ضوابط NCA ECC كمرجع مختار إلى حين قرار الانطباق. ويتطلب انطباق نظام حماية البيانات على المعالجة والنطاق المكاني مراجعة موثقة. ولا يُفعّل CSCC دون دليل تصنيف نظام حرج. وتبقى معايير ISO/IEC طوعية ما لم تُعتمد بصورة مستقلة ويُرخص استخدامها.

النضج الحالي أولي وغير رسمي: توجد ملكيات وسياسات متفاوتة، وتغطية الأدلة غير مكتملة، وبعض الإجراءات متأخرة، ولا يوجد ادعاء امتثال مثالي.
